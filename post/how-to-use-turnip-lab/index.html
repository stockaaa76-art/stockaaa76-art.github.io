Turnip Labの使い方ガイド：日次・週次・月次でサイトを回して投資判断を整理する

Turnip Lab を日次・週次・月次のリズムで回す手順をまとめました。毎営業日は地合い→業種フロー→業種内ランキング→個別銘柄、木曜は信用残、月初はAI銘柄ランキングと業種バリュエーション。掲載データが前営業日の終値である点と、その制約の中での使い分けも解説します。

序文：このサイトは「予測を当てる道具」ではなく「判断を整理する道具」です

Turnip Lab を初めて開くと、指数・ランキング・AI予測・個別銘柄ページと情報が多くて、どこから見ればいいか迷います。ですが、見る順番と頻度さえ決めてしまえば、やることはとてもシンプルです。

まず立ち位置を1つだけ押さえてください。ここは「明日上がる銘柄を当てる」ためのサイトではありません。 翌日の値動きを当てるのは市場が効率的である以上ほぼ不可能で、当サイトの検証でも翌日方向の的中率は五分に近い結果でした。だから使い方は逆で、「地合い → 注目候補 → 個別の質」をデータで手早く整理し、自分の判断からノイズを減らすことに意味があります。

本記事では、その整理を 日次・週次・月次の3つのリズムに落として解説します。毎日やること、週に1回やること、月に1回やることが分かれば、サイトは「眺める場所」ではなく「回す場所」になります。

最初に知っておくこと：数字は「前営業日の終値」です

使い方より先に、データの鮮度を押さえてください。ここを誤解すると、判断の方向そのものを取り違えます。

当サイトのデータは 平日の朝1回だけまとめて更新しています。更新は東京証券取引所が開く前に終わるため、その日の日本株の値動きはまだ入っていません。

サイトに載っている数字使えるか
日本株前営業日の終値その日の取引時間中は、当日の動きが反映されていません
米国株直近の終値米国市場が開くのは日本時間の夜なので、夜の寄り付きまでは最新です

この非対称から、使い分けが決まります。

  • 夜（日本時間の22時台まで） — 米国株を見る時間です。サイトの数字がそのまま最新です
  • 翌朝 — 日本株を見る時間です。前日の日本市場の結果が反映されています

⚠️ 日本株の業種フローを、その日の取引中にそのまま使わないでください。 相場の方向が1日で入れ替わることは珍しくなく、前営業日の「強い業種」が当日は下位、ということが実際に起きます。当日の日本株の動きを踏まえたいときは、翌朝まで待つのが正しい使い方です。

全体像：3つのリズムで回す

リズムいつ見るもの目的
日次毎営業日地合い → 業種フロー → 業種内ランキング → 個別銘柄今日の候補を絞り、保有を点検する
週次木曜信用残（信用倍率・買残／売残）需給の溜まりを確認する
月次月初AI銘柄ランキング・業種バリュエーション中期の候補と、業種の相場観を入れ替える

日次は「広く見て、だんだん絞る」トップダウン。週次と月次は、日次では動かない情報を別のリズムで取りにいく、という分担です。

日次：毎営業日の4ステップ

① 地合いを掴む

最初に開くのは トップページ です。ここでは個別の売買ではなく、「今日は買い向きの日か、様子見の日か」という空気を掴みます。

  • 主要指数の動き — 日経平均・ダウなどが上げているか下げているか。全体が大きく崩れている日は、どんな好銘柄でも一緒に売られやすくなります
  • 世界の指数 — DAX・FTSE・上海・香港・韓国。日米だけ見ていると気づけない流れが出ます
  • 商品・暗号資産 — 金・原油・ビットコイン。リスクを取る日か、避ける日かの温度感が出ます
  • 日本市場全体の売買代金 — 参加者が多い日か、薄商いかの目安です

② 業種フロー → 業種内ランキング

ランキングページ が絞り込みの中心です。ここは 2段階になっていて、この順番がいちばん大事です。

① 業種フロー        17業種の平均騰落を強い順に並べる
                    → 「いま、どこにお金が向かっているか」
          │
          │ 強い業種を見つけたら
          ▼
② 業種内ランキング  その業種を選ぶと、中の銘柄が強い順に出る
                    → 「その流れの中で、どれが主役か」

まず 業種フロー を開いて、17業種の平均騰落を強い順に眺めます。ここで「いま、どこにお金が向かっているか」が分かります。強い業種が見つかったら、そのまま 業種内ランキング へ移り、業種を選んで中の銘柄を強い順に見ていきます。これが「その流れの中で、どれが主役か」です。

いきなり値上がり率ランキングの1位を見るのではなく、まず業種で流れを掴み、それからその中を見る。これだけで「たまたま1銘柄だけ跳ねたもの」を主役と勘違いしにくくなります。

業種内ランキングは 1業種あたり上位10銘柄まで表示します。銘柄数が少なすぎる業種（4銘柄未満）は、平均が1〜2銘柄に振り回されるため対象外にしています。

期間タブを使い分ける

ランキングは 当日・5日・週次・月次・3ヶ月・6ヶ月・年初来（YTD） で切り替えられます。

  • 当日／5日 — 短期の勢い。ただし当日の急騰に飛び乗るのは高値掴みになりやすい買い方です
  • 月次／3ヶ月／6ヶ月 — 数週間〜数ヶ月のトレンド。腰を据えて見るならこちらです
  • 年初来（YTD） — その年の主役を俯瞰します。年の途中で上場したばかりの銘柄は極端な数値になりやすいため、そうした異常値は自動で除外しています

横から当てる3つ

業種フローと組み合わせると、絞り込みの精度が上がります。

見るもの読み方
指数逆行スクリーン指数が下げた期間に上げている銘柄。地合いに逆らって買われている＝相対的に強い候補です
継続上昇と業種集中度当日急騰した銘柄のうち5日続けて上げているもの。1日で終わる急騰と、続いている動きを分けます。あわせて急騰上位の業種の偏りも出るので、テーマ化のサインになります
🔭 新テーマ候補当サイトの予測対象リストの外で急騰している銘柄を自動で拾うコーナーです。リストにまだ入っていない主役を取りこぼさないための発見リストで、買いシグナルではありません

⚠️ 注意喚起のマーカー

マーカー意味
業種逆行（要注意）業種全体が安いのにその銘柄だけ独り高い（＝一過性かもしれない）／業種が高いのにその銘柄だけ独り安い（＝固有の弱さ・減配の兆候かもしれない）
🚫 配当トラップ注意配当利回りが高く見えても、それが「株価が下がったから相対的に高くなっているだけ」の銘柄を検出します

これらは買い・売りのシグナルではなく、立ち止まるための情報表示です。「高配当だから買い」ではなく「なぜ高いのか」を一度考えるためのフラグだと受け取ってください。

③ 保有している銘柄を点検する

候補を探すのと同じくらい、すでに持っているものを見るのが日次の仕事です。

  • 株価が自分の想定した下限に近づいていないか
  • 決算発表が近くないか（株イベントカレンダー で確認できます）
  • 権利落ち日が近くないか

決算の前後は値動きが読めなくなります。決算をまたぐ時期の新規の買い増しは避ける、と決めておくだけでも、避けられる失敗がかなりあります。

④ 個別銘柄ページで「質」を確認する

候補を絞ったら、銘柄一覧から目的の銘柄を検索して詳細ページを開き、最終確認をします。情報は多いのですが、見るべき軸は決まっています。

主要指標とAI月次スコア

PER・PBR・ROE・売上／EPS成長率などの主要指標に加え、その銘柄が AI銘柄ランキングで何位・どのくらい強いかが表示されます。

理論株価レンジ（今・1年後・5年後）

利益と業種平均の評価をもとに、「今の理論株価」「1年後」「5年後」のレンジを表示します。現在値がこのレンジの上限を超えていれば割高寄り、下限を割っていれば割安寄りの目安です。あくまで機械的な参考値で、将来を保証するものではありません。

🧭 投資判断ファネル（このページの主役）

詳細ページの中核が 🧭 投資判断ファネルです。バラバラの指標を4つの問いに整理し、最後に「新規で買うなら／すでに保有なら」の結論の型まで示します。

軸問い
Q1 質持つ価値のある会社か（ROE・財務・成長）
Q2 タイミング今は過熱か・押し目か（価格の位置）
Q3 相対強さ市場・業種に対して強いか
Q4 バリュエーション理論株価に対して割安か割高か

4軸を統合し、「割高すぎるなら見送り」「質は良く押し目なら買い候補」「質が良ければ握る」といった行動の型を提示します。ここで1つ仕掛けがあり、単一のテーマに極端に依存した低PER銘柄は、割安に見えても「テーマが反転すれば剥落しうる一過性の割安」として評価を割り引くようにしています。「安いから買い」の早とちりを防ぐための工夫です。

指数やETF・為替は「会社の質」や「理論株価」の対象外なので、その旨が表示され、価格の位置とトレンドだけを参照する形になります。

週次（木曜）：信用残を見る

ランキングページの 信用残 は、週に1回、木曜に更新されます。日次で追っても動かないので、週の仕事として分けてあります。

  • 信用倍率 — 買い方と売り方のどちらに傾いているか
  • 買残 — 将来の売り圧力になります。積み上がっている銘柄は、上値で戻り売りが出やすくなります
  • 売残 — 将来の買い戻し圧力になります

⚠️ これも買い・売りのシグナルではありません。「同じ上昇でも、買残が膨らんでいる上昇か、そうでないか」を区別するための材料です。

月次：中期の候補と業種の相場観を入れ替える

AI銘柄ランキング（今月の強い銘柄）

1ヶ月先の相対的な強さを機械学習でランキングしたものです。翌日予測とは別物で、更新も月次です。

一覧で眺めるときは ランキングページ を開き、カテゴリの選択で「AI月次ランキング」に切り替えます。⚠️専用のカードは用意していないので、カテゴリから選ぶ以外に辿り着く道がありません。気になる銘柄が出てきたら、銘柄一覧からその銘柄の詳細ページへ進むと、🤖 ML月次スコアに全体の何%ileかが出ます。

過去データをさかのぼった検証（ウォークフォワード）では、市場平均を上回る中央値が出ています。ただし、公開後に実際の1ヶ月を答え合わせした分はまだ4ヶ月分しかなく、そのすべてで市場平均を下回りました。 検証に足る件数が揃うのは2027年初の見込みです。

👉 ですので、これは「当たる予測」ではなく「候補リスト」として使ってください。 ランキング上位というだけで買う理由にはならず、②③④の手順を通したうえでの材料の1つです。当サイトが数字を良く見せないのは、外れたときに「そう書いてあった」と言えないものを載せたくないためです。

業種バリュエーション

業種バリュエーションは、業種ごとの PBR・PER・ROE・配当利回りの中央値を出しています。日本株17業種・米国株11業種が対象です。

使い方は「個別銘柄を業種の真ん中と比べる」ことです。

  • その銘柄の PER・PBR が業種の中央値より低い → 業種の中では相対的に割安
  • その銘柄の ROE が業種の中央値より高い → 業種の中では相対的に質が高い

市場全体の平均と比べると、業種ごとの性格の違い（銀行は PBR が低い、ソフトウェアは PER が高い、など）に引きずられます。同じ業種の中で比べるほうが、割安・割高の判断は正確になります。

積立を実行する日を決めておく

毎月の積立をしている場合は、実行する日をあらかじめ決めて固定するのがおすすめです。「相場を見てから決める」とタイミングを計ることになり、積立の利点である時間分散が崩れます。

1つだけ実務的な注意があります。権利落ち日の直前に買うと、受け取った配当にすぐ課税される分だけ無駄が出ます。 実行日が権利落ち日の直前に重なるときは、数日後ろにずらすだけで避けられます。

Turnip Lab は「予測を当てる魔法のボタン」ではなく、判断のノイズを減らして整理するためのダッシュボードです。この順番とリズムをなぞるだけで、「なんとなく気になった銘柄をいきなり買う」という一番危ない入り方を避けられます。

数字が前営業日の終値である点だけ忘れずに、まずは今夜、米国株のランキングから開いてみてください。
